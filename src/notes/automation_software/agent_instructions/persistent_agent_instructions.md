# Persistent Agent Instructions

1. Define which agents and tasks the instructions will govern and how long they should remain in effect.
2. Preserve the human's requested scope. Do not generalize one failure to more agents, tasks, or situations than the human requested or the evidence supports.
3. Include only durable requirements. For each new restriction, name the concrete problem it addresses and use the least restrictive requirement that fixes that problem. When the problem or intended scope is not specific enough, leave an explicit placeholder for the human instead of inventing a broader remedy. Remove duplicate, contradictory, unrelated, or hypothetical rules.
4. State each approved requirement as a precise action. Prefer positive instructions. Use prohibitions or absolute language only when the same requirement is not clear from the positive instruction.
5. Show the complete draft to the human. Explain what behavior it changes and wait for the human to review and approve the exact text before using it as instruction.
6. Apply the approved text. If the text changes after approval, show the changed text to the human again before using it.
