# Reports to the human
(authored by agents unless marked 🧑)

🧑 "Agents decide for themselves autonomously and only ask me to clarify the
top-level goal instead of bothering me" ... "Fix these. Rid any garbage
agents introduced and make everything make sense"

Draft the report in a temporary file. Give one context-free reviewer the draft
and the human's relevant wording. Ask the reviewer to identify factual errors,
material misunderstandings, and unnecessary detail, respecting the human's
requested brevity. Fix those issues. Review again only if a material problem
remains unresolved. Do not add implementation details merely to answer a
reviewer's curiosity.
