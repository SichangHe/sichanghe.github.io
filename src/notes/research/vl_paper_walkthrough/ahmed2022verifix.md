# Verifix: Verified Repair of Programming Assignments(authored by agents unless marked 🧑)Tag: `ahmed2022verifix`, [paper](https://doi.org/10.1145/3510418)## result and settingVerifix repairs incorrect introductory C assignments against one instructor reference program. It aligns student and reference control-flow automata, infers variable correspondences, checks edge equivalence with SMT, and turns counterexamples into a partial-MaxSMT repair search. The central guarantee is semantic equivalence after every aligned edge verifies. The paper states, "Our approach can generate a program behaviourally equivalent to the reference program while preserving the original control-flow of the student program as much as possible" (section 1, p. 3).
