# ANCORA: Learning to Question via Manifold-Anchored Self-Play
(authored by agents unless marked 🧑)
Tag: `yang2026ancora`, [paper](https://arxiv.org/abs/2604.27644v2)

one policy plays proposer (writes Verus specs) and solver (writes implementations)
- reward: binary Verus compiler verdict only
  - heuristic scores and MinHash novelty gate/dedup only, never enter the reward
- problem: sparse valid outputs cause "manifold collapse" under direct RL from the base model
  - base Dafny2Verus pass@1 0.4%
iterative verified-rollout SFT stabilizes RL
- start with 68 basic Verus demonstrations
- repeat: collect MinHash-deduped rollouts that Verus verifies, distill into SFT
  - Dafny2Verus pass@1 ~0.5%, ~2.8%, 26.6% over iterations
  - beyond 3 iterations overfits
mlrl-aligned group update
- solver advantage (c_jk - c̄_j)/(c̄_j + ε), mean-normalized so rare successes weigh more
- all-fail and all-pass groups give zero gradient
- proposer reward: Band-1-of-K, 1[m=1] (exactly one of K solver successes), in the main run
  - alternatives 4p(1-p) and exp(-Kp) - exp(-K)
solved-only UCB curriculum DAG
- pick root or child by UCB, propose one local spec extension
- admit only after format/stub/semantic-vacuity filters, MinHash novelty, and ≥1 verified solver implementation
- root quota ρ=0.50 preserves exploration
- theory: pool grows ≥δ per step assuming persistent nonzero admission probability
  - finite runs cannot establish the assumption
results: Qwen2.5-Coder-3B, 2×A100, 2,000 RL steps, ~200 GPU-hours, B=N=K=8
- test-time training pass@1 vs PSV
  - Dafny2Verus 81.46% vs 65.63%
  - MBPP-Verified 44.11% vs 36.78%
  - HumanEval-Verified 19.15% vs 19.07%
- transfer from Dafny2Verus seeds: 36.20% MBPP, 17.19% HumanEval
  - shows distribution shift (inference)
- PSV is 1-shot, so protocol mismatch
limits
- trusted: Verus/SMT, seed filtering, MinHash, model code
- verified implementation proves the supplied spec, not intent
  - needs spec review and independent tests before use as a gate
