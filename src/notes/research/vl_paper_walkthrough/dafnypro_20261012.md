# DafnyPro: LLM-Assisted Automated Verification for Dafny Programs
(authored by agents unless marked 🧑)
Tag: `banerjee2026dafnypro`, [paper](https://arxiv.org/abs/2601.05385)

llm regenerates the whole dafny program with annotations, loops up to N=10 attempts with verifier feedback
- 3 components: diff-checker, invariant pruning, hint augmentation
- setup: Dafny 4.11.0, Claude 3.5/3.7 via Bedrock
- full system on DafnyBench (782 programs): 86.18% (3.5), 85.67% (3.7)
  - gains over baseline: ~5% MBPP, 14-16% other datasets
diff-checker for soundness
- parse generated program, strip annotations, require identical base code, else reject before verifying
- fixed all 70/782 base programs that had compile errors (+3.58% Claude 3.5, +3.96% 3.7)
  - ad-hoc annotation removers had caused those errors
- limit: only protects base logic, specs stay trusted
greedy pruning of non-inductive invariants
- remove all verifier-flagged non-inductive clauses, re-verify, keep original if postcondition still fails
- gains: DafnyBench +3.19% / +3.06%, HumanEval +12.26% / +5.66%
- limit: may drop a clause that is useful after later edits
hint augmentation
- 8 fixed problem-independent proof tactics, written manually by an expert
  - e.g. `assert a[..a.Length] == a[..]`, lexicographic `decreases`, conditional boundary invariants
- RetrieveTactics picks relevant ones per attempt; prompt also holds all failed attempts
- gains: +9.97% (3.5), +10.86% (3.7) on DafnyBench
  - unit (points vs relative) not stated by paper
- verus transfer needs adapted syntax and solver behavior (inference)
fine-tuning on verifier feedback
- 31k attempts, LoRA rank 512, N=5, 197 held-out programs
- first-attempt gain: Qwen2.5-7B +23%, Qwen3-14B +13%; 3+2 mix reaches 69.5% after 5 attempts
