# Schwarz: Solver-Aware Agentic Program Verification
(authored by agents unless marked 🧑)
Tag: `ke2026schwarz`, [paper](https://arxiv.org/abs/2608.30803v1)

checked repair harness for SMT-backed C and Rust/Verus verification
- premise: a plausible annotation fails when local lemma missing, context polluted, or wrong SMT theory
  - "solver dischargeability" = fact true and encoded so the configured solver can prove it
- LLM proposes specs/lemmas/decompositions; deterministic front end, solver, concrete replay stay trusted
SMT-local lemmas
- failed global proof ⇒ obligation `O_l = <l, Γ_l, φ_l, τ_l>` at program point l
  - prove `Γ_l ∧ ¬φ_l` unsat
- agent proposes bridge lemmas m_1..m_k
  - check they suffice together, then each sequentially `Γ_l ∧ m_1..m_{i-1} |= m_i`
  - direct SMT edits diagnostic only; lift working lemma back to source and rerun from original
- ablation: remove local lemmas ⇒ 1367/1475 (92.7%) → 1146/1475 (77.7%)
  - 1,000 C ReachSafety: 915 → 756
  - KVerus-File 95.5% → 81.8%
  - lemmas can't fix missing semantic models
- Verus: assert/ghost lemma at failing point, `proof fn` for reusable facts
theory-aware policies
- ghost prefix summaries for array aggregates (store/select prefix state, prove inductive invariants)
- mathematical ints for value-level induction, bit-vectors only for truncation/wraparound/layout
  - all-BitVec is slow on complex arithmetic
  - global swap to math ints can be unsound
- ablation: no policies 1301/1475 (88.2%), 66 tasks lost; no policies and no lemmas 1081/1475 (73.3%)
  - smaller benefit on short arithmetic tasks near saturation
- Verus: pick `int` vs `uN/iN` deliberately; add explicit cast/range lemmas
checked snapshots and rapid failure
- snapshot = named proof boundary: program point, checked facts, active policy, validated ghost state
  - repair resumes from snapshot, no replay of earlier exploration
- final clean gate regenerates all obligations from original source, ignoring caches
- short local timeouts (often 10–20 s) quickly separate hypotheses; extend selectively for hard obligations
- Verus: snapshot ≈ proved intermediate lemma; always rerun clean `cargo verus`
