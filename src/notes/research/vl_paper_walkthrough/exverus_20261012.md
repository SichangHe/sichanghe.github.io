# ExVerus: Verus Proof Repair via Counterexample Reasoning
(authored by agents unless marked 🧑)
Tag: `yang2026exverus`, [paper](https://arxiv.org/abs/2603.25810)

LLM repair loop for failing Verus proofs
- soundness boundary: Verus rechecks every candidate; Z3 query synthesis, triage, mutation are untrusted search
- initial proofs come from AutoVerus; no spec or initial-annotation synthesis
source-level counterexample synthesis
- LLM translates failing obligation into compact Z3Py over source variables, avoiding Verus's lowered SMT
- may concretize variables to dodge quantifiers; regenerate on failure
- ten counterexamples solve 106/187 InvariantInjectBench tasks vs 100/187 with one
- risks: hallucinated constraints, spurious states, generation not guaranteed
verifier-based validation (invariant errors only)
- extract loop into `loop_func`, turn invariants into assertions before/after one body, inject assignment at entry
  - `InvFailFront`: start assertion fails; `InvFailEnd`: start holds, end fails
- mutants blocking ≥1 validated counterexample verify 64.49% (158/245) vs 38.55% (32/83) for none
  - repaired tasks 80.39% (41/51) vs 42.86% (9/21)
  - correlation, not causation
- assertion errors may lack a well-defined counterexample (e.g. missing trigger)
triage-directed mutation
- LLM labels examples reachable (invariant wrong: replace) or spurious (non-inductive: strengthen)
- 5 mutants per round, ranked by blocked counterexamples (non-invariant errors: verified sub-goals), ≤10 rounds
- ablation (DeepSeek): VerusBench 64.4% to 71.9%, ObfsBench 65.4% to 81.6% with mutation plus validation
cost and caveats
- DeepSeek-V3.1: $0.04/task vs AutoVerus $0.17 (4.25x), 720s vs 2989s
- GPT-4o: $0.42 vs $0.69, 250s vs 234s, so not faster
- text says ExVerus above 73% and AutoVerus below 40% on all obfuscations except GPT-4o
  - Table 2 contradicts: ExVerus 65.2% (Qwen3-Coder, dead code), AutoVerus up to 77.3% (Sonnet-4.5, opaque predicates)
- VerusBench uses 146 of 150 tasks (4 no longer verify)
