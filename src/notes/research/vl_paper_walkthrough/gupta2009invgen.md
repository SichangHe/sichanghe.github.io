# InvGen: An Efficient Invariant Generator(authored by agents unless marked 🧑)Tag: `gupta2009invgen`, [paper](https://www.semanticscholar.org/paper/2780dd83b79ed76ed21f641264582126cd803cf5)## what the paper doesInvGen synthesizes linear-arithmetic loop invariants by instantiating user-supplied templates. It translates each cut-point path's Hoare-triple inductiveness condition into arithmetic constraints over template coefficients, then combines static and dynamic information to solve those constraints faster. The paper's abstract states: “InvGen’s unique feature is in its use of dynamic analysis to make invariant generation order of magnitude more efficient.” (abstract, p. 634)A template is a Boolean combination of linear inequalities whose coefficients are parameters. The tool returns an invariant proving that the error location is unreachable, or fails (Section 2, p. 634). The source language is C syntax or a transition relation over linear arithmetic expressions (Section 2, p. 634).## technique: template-based constraint synthesiswhat it is and when to use itUse a template when the expected invariant can be expressed as parameterized linear inequalities at loop-entry cut points. The template gives the solver a fixed shape while leaving coefficients unknown. This is appropriate for linear arithmetic loops and is less suitable when the needed predicate is nonlinear or has an unanticipated Boolean structure.how to do it1. Choose cut-point locations, normally loop entries, and attach a parameterized template `η(ℓ)` to each (Section 3.1, p. 635).2. Set the start-location template to `true` and the error-location template to `false` (Section 3.1, p. 635).3. For every path between adjacent cut points, require the Hoare triple `{η(ℓ)} path {η(ℓ')}` to be valid. Translate these implications into arithmetic constraints over template parameters (Section 3.1, p. 635).4. Solve the resulting constraints. Any satisfying assignment instantiates a safe invariant (Section 3.1, p. 635).The paper's `simple.c` example uses `αx x + αn n ≤ α` at the loop entry. The three paths are initialization, one loop iteration, and the path from loop exit to the error assertion. The solution `αx = 1`, `αn = −1`, `α = 0` yields `x − n ≤ 0` (Section 3.1, pp. 635–636).Verus form
