# Clover: Closed-Loop Verifiable Code Generation
(authored by agents unless marked 🧑)
Tag: `sun2023clover`, [paper](https://arxiv.org/abs/2310.17807)

problem: a verifier proves code meets annotations, not that annotations match intent
- clover filters code + annotations (pre/post) + docstring triples
- accept only if 6 pairwise checks pass
  - 1 verification (anno-sound), 5 llm regenerations tested for equivalence
- agnostic to how the triple was generated, filters but does not repair
- assumes each artifact determines a unique output
six edges
- anno-sound: dafny verifies code against annotations
- anno-complete: regenerate code from annotations only (anonymized name), compare to original
  - guards against trivially weak annotations
- doc2code: code from docstring, compiler feedback only, compare to original
- code2doc: docstring from code with precondition embedded as assert, judged equivalent
- doc2anno: annotations from docstring, proved equivalent to original in dafny
- anno2doc: docstring from annotations, judged equivalent
- m = 3 tries with compiler feedback, optional k repetitions per edge, pass if any passes
techniques
- annotation equivalence: wrap original and generated pre/post in predicates, two empty-bodied equivalence lemmas
  - sound but incomplete, e.g. `only_once` multiset vs index formulation not proved
  - verus: lift `Vec` to `Seq`, `&mut` needs old and new params, precondition on `proof fn` only
- code equivalence: same output on 5 fixed test inputs, weak
  - anno-complete rejects only 26/60 (k=1), 16/60 (k=10) of weakened-annotation (C2) variants
- docstring equivalence: fresh memoryless gpt-4 call, weakest part
  - misses added or omitted info, only catches contradictions
- prompts ask for weakest pre and strongest post, ban noise clauses and helper functions
- sample-then-filter: 20 gpt-4 samples per problem
  - 41/60 have a correct sample, clover accepts a correct one for 39, accepts no incorrect
- adversarial variants that still verify (C1 docstring, C2 weaker annotations, C3 both, C6 code+annotations)
  - dafny alone would have 100% false positives
  - no single edge rejects all of C1/C3, the conjunction is needed
  - hand-built by the authors, bounds false positives loosely
results (gpt-4, dafny 4.0.0)
- cloverbench ground truth: 45/60 accepted (75%) at k=1, 52/60 (87%) at k=10
- adversarial: 0/240 accepted at both k
- mbpp-dfy-50: 24 accepted of 27 correct, 33 in scope, 17 of 50 out of scope
- verus, 41 examples: 32/41 at k=1, 36/41 at k=10
  - no adversarial variants for verus, so no verus false-positive measure
- codellama-34b: all six edges pass only 2/60
limits
- shared blind spots pass, e.g. docstring, annotations, code all miss one edge case
- one method only, no helper functions or predicates
- most ground-truth rejections are gpt-4 writing invalid dafny syntax
- paper theory bounds one edge's accept probability, edges not independent
  - measured whole-check 0.75 vs product 0.59
- table 4 anno2doc k=1 count 24/60 is likely the accepted count, not 60%
