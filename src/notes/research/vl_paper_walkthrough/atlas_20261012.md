# ATLAS: Automated Toolkit for Large-Scale Verified Code Synthesis
(authored by agents unless marked 🧑)
Tag: `baksys2025atlas`, [paper](https://arxiv.org/abs/2512.10173v2)

pipeline producing verified Dafny training data
- input: NL contest problem, reference solution, I/O tests
- output: Dafny spec, implementation, proof annotations, tests
- 2,751 verified programs from 12.8K TACO-verified problems, 19,385 training examples
- fine-tuned Qwen 2.5 7B Coder
  - DafnyBench Pass@5 32.4% to 56.9%
  - DafnySynthesis Pass@5 15.8% to 65.8%
- trust boundary
  - proofs cover only implementation vs generated contract
  - NL task, reference solution, contract, tests, LLM judge are untrusted
freeze the contract before synthesis
- generate signature, `requires`/`ensures`, tests, compile-check
- implementation may not weaken preconditions
  - postconditions must be a superset of the original
  - whole program verifies and passes tests
- freezing itself has no ablation
  - removing soundness/completeness checks: 65.8% to 58.4%
  - removing tests from fine-tuning: 59.6%
- error-correction loops tend to weaken postconditions
spec quality checks
- soundness lemma: fix input and expected output, check the postcondition holds
  - failure means the contract rejects a known-correct example
- completeness by contradiction: assume a different output, prove false
  - provers often cannot do this
- completeness by perturbation: LLM mutates the expected output, check the contract rejects it
  - sampled and bounded, not a proof of completeness
verification-run curriculum
- keep failed attempts as correction data
  - repairs over 35% of the dataset
- tasks: NL-to-Code 2,751, NL-to-Spec 5,225, Spec-to-Code 2,751, spec repair 2,353, impl repair 4,562, proof infill 1,743
- yield falls with difficulty
  - 47.14% on 5,456 easy samples
  - 19.93% on 537 very hard samples
- ~1K programs verify without hints, 1.7K are proof-infilling
Verus translation (inference)
- ATLAS does not evaluate Verus
  - freeze `requires`/`ensures`, add proof code only
  - filter artifacts with unjustified `assume`, `admit`, `external_body`
