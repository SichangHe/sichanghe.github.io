# Goedel-Code-Prover: Hierarchical Proof Search for Open State-of-the-Art Code Verification
(authored by agents unless marked 🧑)
Tag: `li2026goedel`, [paper](https://doi.org/10.48550/arxiv.2603.19329)

task: Lean proof of `∀ x, P x → Q x (C x)` for already formalized program and contract
- spec formalization and code generation out of scope
decomposition with two gates
- LLM proposes lemmas + parent reconstruction proving their conjunction implies goal
  - reconstruction must use every lemma, checked by Lean
- quickcheck each lemma on sampled inputs, discard whole decomposition on any counterexample
  - needed because a false lemma can trivially prove the parent
  - quickcheck rejects only, closing all leaves proves
operator-footprint score ranks decompositions
- d(G) = count of logical/domain operators in Lean AST
- r = max(1 - logsumexp-aggregate of children d / d(G), 0), times validity gate
- same score is GRPO reward and inference ranking
- heuristic only; in Verus, SMT difficulty also depends on triggers and nonlinear arithmetic
training
- distill 281K decomposition + 151K completion pairs from GPT-5.2 / Gemini-3-Flash into Qwen-3-8B
- GRPO on decomposition score, supervised replay for completion
- successful lemmas expand the problem set
  - SFT vs RL on Verina pass@32: 66.1% vs 68.8%, single run
bounded hierarchical inference
- repeatedly decompose largest-footprint open goal: 128 iterations, 32 open goals cap
- then prove leaves with Lean error refinement, 128 iterations
eval: 427 tasks, 62.0% overall (about 265/427)
- Verina 68.8%, Clever 54.0%, AlgoVeri 62.3%
- Clever/AlgoVeri code generated by GPT-5.2 and manually checked
- not compute-matched: baselines pass@128 on whole proofs
- accepts only propext, Classical.choice, Quot.sound axioms
Verus transfer (inference)
- helper `proof fn`s with `requires`/`ensures` as lemmas
- controller must parse Verus diagnostics, no tactic goals
