# Kani: A Model Checker for Rust
(authored by agents unless marked 🧑)
Tag: `delmas2026kani`, [paper](https://doi.org/10.1145/3832783.3834499)

kani = rust model checker: rustc MIR -> CBMC GOTO -> bit-precise SAT/SMT
- guarantee conditional on harness coverage, assumptions, sound contracts/stubs, unsupported features
- unsupported/trusted: concurrency, dyn dispatch, some FFI, Stacked/Tree Borrows aliasing, recursion termination, MIR-to-GOTO translation, solver
  - paper calls aliasing UB "the primary class of UB in unsafe Rust"; suggests Miri as complement
bounded harness checking = push-button first step
- `#[kani::proof]`, `kani::any` inputs, `kani::assume` real preconditions, `assert!`
- auto checks: panics, overflow, bounds, invalid deref, bad discriminants, div by 0, unwrap on None
- every loop needs `#[kani::unwind(k)]`; failing unwinding assertion = inconclusive, not proof
- `assume(false)` makes proof vacuous; review assumptions like code
- finite bound can be sound yet intractable
  - gcd, unwind 94 is complete for u64, but full range did not finish in 1 hour
- evidence: 11 bugs missed by testing/fuzzing in 4 production codebases
  - s2n-quic bug survived 16,777,216 fuzz runs, Kani found it in 20 s
function contracts = compositional abstraction
- `requires`, `ensures`, `modifies` (inferred for `&mut`, required for raw pointers), `old(e)`
- `proof_for_contract(f)` verifies, `stub_verified(f)` at callers: assert pre, havoc write set, assume post
- frame rule assumes no aliasing in/out of write set; safe Rust gives it, unsafe callers must establish it
- gcd contract proves in 0.54 s (202 checks); hours of unwinding in caller become seconds
- weak postcondition (result > 0) chosen because Z3 cannot instantiate the quantifier over nonlinear 64-bit remainder
- recursion: partial correctness only, mutual recursion rejected
loop contracts for when unwinding is too costly
- `loop_invariant`, `loop_modifies`, `loop_decreases` (integer measure only, no lexicographic)
- body executed twice (base + inductive step) with havoc between, so time independent of iteration count
- without `loop_decreases` only partial correctness, Kani warns
- Hifitime `Mul<f64>`: 0.2 s vs 91.8 s unwinding
quantifiers and stubs
- `forall!`/`exists!` over ranges; SAT backends expand eagerly (warn above 1000), SMT backends take runtime bounds but instantiation can fail
- `kani::stub(f, g)` for FFI/clock/random/expensive code; plain stub is trusted, unchecked against f
evidence from adoption
- Hifitime: 11 -> 168 harnesses (158 generated), 57 generated timed out at 60 s; contract phase 153 proofs, 6 new bugs
  - paper's 11 + 158 = 169 vs 168 unreconciled
- CI: Firecracker 34 harnesses/21 min, s2n-quic 102/23 min, std lib 16,748/69 min
- authors admit projects self-selected, over-representing favorable cases
relevance to agent-written Verus
- inference: Kani = exhaustive gate for panic/memory safety, low annotation
- agents can write vacuous assumptions, weak postconditions, unsound stubs, partial-correctness invariants
- record unwind completeness, contract/stub provenance, solver, timeouts, unsupported features
- Verus better for rich ghost state; `requires`/`ensures`/`invariant`/`decreases`, `old(x)`; proves for all inputs, may need more annotations
