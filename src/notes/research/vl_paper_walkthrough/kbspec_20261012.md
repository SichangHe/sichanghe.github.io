# KBSpec: LLM-driven Formal Specification Generation with Evolving Domain Knowledge Base
(authored by agents unless marked 🧑)

JML spec generation with a memory that learns from verifier feedback (Wang & Sun)
- verifier: OpenJML on Java; no Rust/Verus implementation, mapping is inference
- memory evolves with no LLM weight updates
dual-source knowledge base
- external seed: official docs, 83 items (11 examples, 31 tutorials, 26 exercises, 15 repair guides)
- internal: items from successful generation and repair trajectories
  - dominates final memory; repair-derived items largest
- item = content + LLM summary + keywords; retrieve by embedding program (and verifier error in repair)
baseline-attributed credit
- one retrieved item per generation, compared with knowledge-free baseline
  - fail to pass = helpful, pass to fail = harmful, else neutral
- score = (helpful - harmful) / (helpful + harmful + neutral + 1e-6); keep top L
- dedup new items at cosine 0.95
- caveat: credit measures verifier success not completeness
  - weakening postconditions is 33.0-51.2% of learned repair items
iterative repair with partial credit
- up to 3 rounds, retrieve with current spec + error
- partial progress p = fraction of errors that disappeared; regression penalty q for resurfaced errors
- ablation: removing iterative repair lowers C@All by 13.33-21.82 points
  - removing partial credit lowers C@All 1.53-3.40
- loop reasoning 16.6-24.0% and arithmetic 14.7-22.5% of learned repair items
  - classified by keyword matching, unvalidated
results (699 FormalBench-Base Java programs, frozen memory, top-3 retrieval)
- pass rate 73.96% GPT-5.2, 47.35% GPT-5-mini, 62.66% Claude-Sonnet-5 vs SpecGen 41.63 / 28.18 / 47.93
- C@All (mutation completeness, 0 if no passing spec) 38.51 / 30.92 / 39.46
  - C@Pass lower than SpecGen on all three backends
Verus takeaways (inference)
- retrieved text is advice; every annotation must pass the pinned Verus
- parse diagnostics into stable categories, keep original spec to detect weakening
- report pass, timeout, internal error denominators separately
