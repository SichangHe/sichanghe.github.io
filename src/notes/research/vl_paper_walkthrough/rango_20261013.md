# Rango: Adaptive Retrieval-Augmented Proving for Automated Software Verification
(authored by agents unless marked 🧑)
Tag: `thompson2024rango`, [paper](https://arxiv.org/abs/2412.14063)

system: writes Coq proofs one tactic at a time with a fine-tuned DeepSeek-Coder 1.3B
- before each tactic, retrieves in-project proofs and lemma statements similar to the current goal
- headline: 3,325 / 10,396 theorems (32.0%) in 10 min
  - Tactician 2,575 (24.8%), Proverbot9001 2,007 (19.3%)
- Coq is the only judge; theorem statements are taken as given
retrieval is the main gain
- proof retrieval: score each banked proof by its best BM-25 match between any intermediate proof state and the current state, rerun after every tactic
  - bank = proofs earlier in file or in its dependencies, current project only
  - ablation on 500 theorems: full 30.0%, no lemmas 29.0%, no proofs 20.4%, no retrieval 18.6%
  - BM-25 32.0% > TF-IDF 31.7% > CodeBert dense 22.0%
- lemma retrieval: TF-IDF over lemma statements, small effect
  - 150 vs 145 of 500, within sampling noise (inference)
- fine-tune on prompts built exactly as at inference, fixed token budget per part
  - 1,024 proofs, 512 lemmas, 512 theorem + script, 1,024 proof state, 128 output
  - retrieval substitutes for training on the project
search and ensembling
- rollout search: sample tactic at temperature 1.0, restart from scratch on error
  - 30.0% vs best-first beam 28.4% vs best-first sampling 25.0%
  - weakness: ignores earlier failed attempts
- prefix retrieval (file text above theorem) alone: 31.3%, only 0.7 points behind full Rango
  - Rango-Hybrid alternates both across rollouts: 33.5%
  - the 47% headline gain is against a model with no project context, not one seeing the prefix
- union with another tool: Tactician 37.2%, Proverbot 35.8%
  - budget of both tools not charged
benchmark
- split by project, not file; exact-statement matches removed from training
  - 2,208 training repos, 12 benchmark repos with 10,396 theorems
- post-cutoff projects: Rango 30.1% vs Tactician 28.3%
  - margin shrinks from 29% to 6%; contamination cannot be separated from project differences
caveats
- CompCert supplies 59% of benchmark theorems
- Graph2Tac closer on a 496-theorem subset (276 vs 265), different Coq version
- GPU for Rango vs CPU for baselines
verus form (inference)
- no tactic-level state: nearest is the failing obligation
- bank = `proof fn` signatures from crate and vstd, query = failing obligation
- rollout = resample whole annotated function and re-verify
- prefix retrieval is free: file text above the function
