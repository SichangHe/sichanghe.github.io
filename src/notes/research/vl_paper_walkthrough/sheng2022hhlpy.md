# HHLPy: Practical Verification of Hybrid Systems using Hoare Logic(authored by agents unless marked 🧑)Tag: `sheng2022hhlpy`, [paper](http://arxiv.org/abs/2210.17163v2)## scope and modelHHLPy verifies the sequential fragment of Hybrid Communicating Sequential Processes (HCSP), where discrete commands are combined with deterministic ordinary differential equation (ODE) evolution. The paper’s abstract says: “We present a tool for verification of hybrid systems expressed in the sequential fragment of HCSP.” (Abstract, p. 1) A Hoare triple `{P} c {Q}` means every terminating execution from a state satisfying `P` ends in a state satisfying `Q` (Section 3, p. 3). An ODE `⟨ẋ = e & D⟩` evolves until polynomial domain `D` becomes false; unlike differential dynamic logic, HCSP continues deterministically to the boundary (Section 2.1, p. 2).## technique 1: invariant-based ODE rulesWhat it is. HHLPy represents continuous proof obligations as invariant triples `⟦D⟧⟨ẋ=e⟩⟦I⟧`: every solution that stays in domain `D` preserves invariant `I`. It supplies differential weakening (dW), differential invariant (dI), differential cut (dC), differential ghost (dG), barrier certificate (bc), and Darboux (dbx) rules (Section 3.1, pp. 3–5).How to apply it.1. Write the ODE domain, desired postcondition, and one or more polynomial invariants. Use dW to split the initial state into the domain case and the already-outside-domain case. The paper explains: “The precondition (D → I)∧(¬D → Q) corresponds to the two cases for the state before ODE.” (Section 3.1, p. 4)2. For each invariant equality or inequality, compute its Lie derivative along the ODE. dI proves `f=0` when the derivative is zero, `f<0` when it is nonnegative, and `f≠0` when it is zero (Section 3.1, p. 4).3. If one invariant simplifies another proof, apply dC: first prove `Q1`, then prove `Q2` assuming `Q1`, yielding `Q1 ∧ Q2` (Section 3.1, p. 4).4. If the needed invariant is not expressible in the original variables, add fresh differential ghost variables with Lipschitz dynamics and prove an invariant in the extended system (Section 3.1, p. 5).5. Alternatively, use a barrier certificate when `f=0` has strictly positive derivative, or a Darboux certificate when `ḟ = g f` (Section 3.1, pp. 5–6).The paper’s concrete example proves `y=5` for `ẋ=1,ẏ=1` while `x<5`, using invariant `x−y=0`; the resulting boundary condition is `x=5 ∧ x−y=0 → y=5` (Appendix A.2, pp. 20–21). Its ghost example adds `ẏ=−y²` to prove positivity of `ẋ=x` (Appendix A.5, pp. 21–22).Verus form.
