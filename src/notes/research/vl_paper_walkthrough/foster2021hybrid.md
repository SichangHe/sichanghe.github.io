# Hybrid Systems Verification with Isabelle/HOL: Simpler Syntax, Better Models, Faster Proofs(authored by agents unless marked 🧑)Tag: `foster2021hybrid`, [paper](https://doi.org/10.1007/978-3-030-90870-6_20)## frameworkThe paper extends an Isabelle/HOL shallow-embedding framework for hybrid programs. Its abstract lists three changes: “an algebraic model for hybrid program stores, a shallow expression model for hybrid programs and their correctness specifications, and domain-specific deductive and calculational support.” (Abstract, p. 1) The resulting workflows either certify a unique ODE solution and use it for weakest-precondition reasoning, or assert invariant sets and prove them abstractly (Section 1, p. 2).Programs are state transformers. Sequential composition, choice, tests, and iteration are interpreted algebraically; partial correctness is `P ⊆ wlp α Q`. Continuous evolution maps an initial store to all reachable states along ODE solutions that respect a guard (Section 2, pp. 3–4). The framework therefore separates executable program structure from mathematical flow and invariant proofs.## technique 1: lens-based hybrid stores, frames, and projectionsWhat it is. A lens has `get` and `put` operations for a variable or substore and satisfies round-trip laws. Independent lenses commute. Lens sums represent variable sets, composition projects vectors, and frames describe variables a command may mutate. The paper states: “This makes reasoning about hybrid stores local.” (Section 3, p. 5)How to apply it.1. Declare a `dataspace` with typed constants, assumptions, and variables. Isabelle creates a lens for each variable and independence assumptions (Section 3, p. 5).2. Combine independent variable lenses with sum to represent a frame such as `{x,y,z}`; use composition and quotient to project a vector or local continuous store (Section 3, pp. 5–7).3. Define `α nmods A` to mean command `α` leaves frame `A` unchanged. Prove non-modification compositionally from assignments and branches (Section 3, p. 6).4. Apply the frame rule: if `α` does not modify `A`, predicate `I` mentions no `A` variables, and `{P} α {Q}` holds, conclude `{P∧I} α {Q∧I}` (equation (1), p. 7).The water-tank example declares discrete pump state `flw`, continuous level `h`, measurement `hm`, and time `t`. An ODE assigns derivatives only to `h` and `t`; the frame system proves `flw` and `hm` unchanged, allowing controller invariants to be reused (Section 7, pp. 12–13).Verus form.
