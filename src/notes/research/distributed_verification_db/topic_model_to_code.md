- ESBMC-Arduino hardware-faithful PLC verification (2026)
    - title: ESBMC-Arduino: Closing the Deployment Gap for Formal Verification of Open-Hardware PLCs
    - what: Introduces a hardware-faithful verification method for IEC 61131-3 programs on open-hardware PLCs and instantiates it as ESBMC-Arduino. A declarative HAL fixes MCU word width, ADC/PWM resolutions and I/O bindings; the lowering injects realizable input bounds and bit-precise arithmetic before ESBMC BMC/k-induction. The paper formalizes the deployment gap as disagreement between an abstract model with unbounded integers/free inputs and a device model with finite-width arithmetic and hardware domains. It defines HAL H=<w,badc,bpwm,mu>, gives four lowering transformations (width, input assumes, quantization/PWM clamp, nondeterministic nonlinear abstraction), and proves Reach_device subset Reach_model under a faithful descriptor, with every reported counterexample physically realizable. The motivating adc*100 alarm flips at AVR adc=898. Controlled variants isolate vulnerable scaling versus safe offsets/comparisons. The 123-program corpus finds 54/123 naive false alarms, all unphysical IN-5 underflows; HAL bounds reduce 54 to 0 while retaining 32 proofs. CBMC and Frama-C mirrors reproduce the phantom and genuine width defect.
    - number: 123 real programs; naive 54 unsafe, 37 unknown, 32 safe
    - number: HAL annotated: 0 unsafe, 91 unknown, 32 safe; all 54 false alarms removed
    - number: Controlled median solve time 168 ms, maximum 412 ms; real runs under 1 s
    - number: CBMC reproduces 54/54 naive overflows and bounds remove 54/54
    - limits: Scope is integer/Boolean IEC logic and model-level verification, not hardware-in-loop. Scan-cycle sampling ignores plant dynamics, sensor noise and actuator latency. Soundness depends on correct HAL word width and per-input ranges; uniform 10-bit AVR treatment can be wrong for wider ADC, network or digital-word inputs. Nonlinear blocks are sound but imprecise nondeterministic ranges, and k-induction leaves 91 real programs unknown. Binding and quantization mechanisms are future work.
