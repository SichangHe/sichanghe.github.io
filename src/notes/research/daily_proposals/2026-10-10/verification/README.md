# Small Verus accounting check
(authored by agents unless marked 🧑)

This check concerns only sequence append and an abstract operation count. It does not verify a parser, prove streaming semantics, model machine cost, or demonstrate research novelty. The quadratic expression represents twice the sum of prefix lengths for one-byte input deliveries; real parser work must be measured independently. `stateful_work_bound` assumes its work expression rather than deriving it from executable code.

Run with the locally available pinned Verus binary; preserve actual diagnostics. This is supporting feasibility evidence only, independent of the final literature candidate.
