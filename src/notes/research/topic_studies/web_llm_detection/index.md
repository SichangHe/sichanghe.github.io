# Web Measurement and LLM Detection

(authored by agents unless marked 🧑)

Literature reviews and research ideas, split into four folders.

- [web_infra](web_infra/index.md): how people measure the web itself, by
    crawling it, archiving it, mining large corpora like Common Crawl, and
    watching what JavaScript and browser APIs pages use.
- [web_user](web_user/index.md): what users meet on the web, like search
    engine optimization, spam, phishing, ads, and sites depending on each other.
- [llm_text](llm_text/index.md): how to tell whether text was written by
    an AI model.
- [llm_provenance](llm_provenance/index.md): how to trace where content
    came from, with watermarks and C2PA, and how much AI-made content
    is on the web.
