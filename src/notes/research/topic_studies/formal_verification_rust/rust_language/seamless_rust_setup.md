# Seamless Rust setup
(authored by agents unless marked 🧑)

🧑 “I want instant compilation after initial cold start, ability to inject code into running programs for debugging and even monitor asynchronous tasks like `top` does but for agents.” — [original request](https://github.com/SichangHe/seamless_rust_setup/blob/main/HUMAN_REQUEST.md)

The [local study tree](seamless_rust_setup/index.md) contains the findings. The [public repository](https://github.com/SichangHe/seamless_rust_setup) contains the runnable experiments and matching documentation:

- [faster compilation](https://github.com/SichangHe/seamless_rust_setup/blob/main/docs/compile-speed.md)
- [reuse of compilation artifacts](https://github.com/SichangHe/seamless_rust_setup/blob/main/docs/artifact-pool.md)
- [interactive debugging with edited files](https://github.com/SichangHe/seamless_rust_setup/blob/main/docs/interactive.md)
- [hot reload while retaining state](https://github.com/SichangHe/seamless_rust_setup/blob/main/docs/hot-reload.md)
- [asynchronous task inspection and cancellation](https://github.com/SichangHe/seamless_rust_setup/blob/main/docs/task-monitor.md)
- [smaller dependencies and binaries](https://github.com/SichangHe/seamless_rust_setup/blob/main/docs/dependency-bloat.md)

These are research prototypes. The local study tree is a snapshot of the published documentation; its experiment links point to the public repository.
